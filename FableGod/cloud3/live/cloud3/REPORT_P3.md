## 9. Rejected rows: REACH-CUT-X, and the metric that was wrong for them (00:5x; `scripts/sim_reachx.py`) [P on D1]
- In the engine, rows after a check's first miss are discarded: a flip on such a row never reaches the output. A flip matters only on a REACHED row (every earlier draft accepted): there it either rejects a right draft (a wrong correction is emitted) or mis-corrects / falsely accepts at the first miss. The decision map's "all-row flips" count every realized row, and 18 / 36 / 37 % of realized rows (code / IFEval / multi) are after the first miss. CHECKED (section 12, `scripts/sim_reached_flips.py`): joining floor_rows.json's per-position flips with the live-cut checks, the flip RATE on reached rows is 5-12 % lower than the all-row rate on code (topk2 3.95 vs 4.47 %, topk5 1.51 vs 1.73 %) and equal on chat (26.6 vs 26.6 %; 11.4 vs 11.8 %): wasted rows are not more fragile than reached ones, so the all-row rate is a fair proxy per row. What the engine changes is WHICH rows a reach rule cuts (rows that are rarely reached), not the rate per row. The reached-row read-out (REQUESTS C3-R9) is therefore a precision, not a correction; it matters for REACH-CUT, whose cut rows are almost never reached (below).
- REACH-CUT-X: unsure rows with reach < tau run at top-2 + union (REACH-CUT), and if the first miss lands on such a row its correction is NOT emitted: the check ends at the previous row and the next check re-verifies from there exactly. Measured: at tau 0.5 the first miss lands on a cheap row in 0.0 % of checks on all three domains (cheap rows are reached only when every unsure row before them was accepted); reached cheap rows per check 0.10 / 0.07 / 0.04; kept per check unchanged (x1.000). At tau 0.7: cheap rows 4.6 / 14.3 / 17.1 % of rows, the exact re-run fires on 0.8 / 0.7 / 0.2 % of checks, kept x0.999 / 0.997 / 0.999. So the only live deviation of REACH-CUT at tau 0.5 is a false accept on 0.04-0.10 reached cheap rows per check, and the X rule costs nothing: REACH-CUT is nearly exact BY CONSTRUCTION; its map verdict (PASS code 1.28 %, BETWEEN chat) counts flips on cut rows that are reached in 0.04-0.10 rows per check, i.e. its live deviation is a small fraction of the map's number (the map perturbs every cut row, reached or not). Union saving: x0.88 of the Q1-0.9 count on code, x0.81-0.84 on chat (P1 section 2); on T2: x0.93 / 0.87 / 0.87 (section 1 of this file).
- What remains of the rejected rows after reach: the rows between the first miss and the cut that have reach >= 0.5 (the drafter was confident and wrong): 14 % of code's union and 26-28 % of chat's at the live cut (33 % with stand-ins) minus what reach removes; no realizable signal names them (STOPPRED, K-HEAD KILL), and the next check re-reads them anyway.
