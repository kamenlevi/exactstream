# Draft-side union control: EcoSpec "Less Experts, Faster Decoding: Cost-Aware SD for MoE" (arXiv 2607.12696, 14 Jul 2026; Xie, Liu et al.) and EVICT "Making Every Verified Token Count: Adaptive Verification for MoE SD" (arXiv 2605.00342, May 2026)
- Links: https://arxiv.org/abs/2607.12696 ; https://arxiv.org/abs/2605.00342. Source: WebSearch extracts [S].
- EcoSpec: names the problem "expert scattering" (high-probability draft tokens route to disjoint experts). A lightweight (target-specific, fine-tuned per AcceptMoE's description) expert predictor plus a dynamic expert buffer steer DRAFT-TREE selection toward paths that keep acceptance likelihood high while reusing experts already in the verification set; the target's verification rule is unchanged (lossless). DeepSeek-V3.1 671B, Qwen3-235B-A22B, GPT-OSS-120B: smaller active expert footprints, up to 1.62x end-to-end.
- EVICT: prunes the draft TREE adaptively (branches that would expand the union are cut); up to 2.35x over AR, 1.21x over EAGLE-3 on average.
- Maps to us: EVICT's form is the t 0.3 running-confidence truncation (ADOPTED; NOVELTY tags it EVICT / DraftExpert). EcoSpec's form is untried here: our drafter emits ONE chain (no tree), so the only choice is between the drafter's top candidates at each depth; M-10 measured a sibling adds 2.35-2.55 new experts per layer vs 2.79 for a chain row (0.84-0.91x), i.e. candidates differ little in union cost; and the top-1 draft is right 93 % of the time on code, so choosing the top-2 token for its cheaper route costs acceptance. Expected [G]: < 5 % union at a kept loss of the same order; a CPU test exists (traces with top-20 routes: pick at each depth among the drafter's top-2 the token whose route adds fewer new experts, count union and kept with the drafter's own probabilities).
- TRIED status: EVICT = ADOPTED (t 0.3); EcoSpec draft-path choice: untried, low prior.
- Open: EcoSpec's predictor accuracy vs the cost of running it per candidate (our drafter already has the taps; a route predictor from drafter states is LEAD1CORR-class, recall@10 ~0.73).
