# Per-layer / per-token expert skipping: LExI (arXiv 2509.02753), Fine-grained MoE skipping / ASET (Yang et al., ACL Findings 2026), ACE (arXiv 2609.05228), HookMoE (EMNLP 2025), PCoMoE (2609.01024), Expert-Sample (2602.02443)
- Links: https://arxiv.org/abs/2509.02753 ; https://aclanthology.org/2026.findings-acl.2140 ; https://arxiv.org/abs/2609.05228 ; HookMoE https://aclanthology.org/2025.emnlp-main.1610 ; https://arxiv.org/abs/2609.01024 ; https://arxiv.org/abs/2602.02443 (the last three from GOAL.md:173-176; not re-found by search tonight). Source: WebSearch extracts [S] + GOAL.md.
- LExI: post-training, data-free per-LAYER top-k: profile each layer's perturbation loss under synthetic inputs, then an evolutionary search sets k per layer under a total budget B with per-layer bounds; Qwen1.5-MoE: +10 % accuracy at equal throughput vs expert pruning on H100 (another summary: +5.1 % throughput).
- Yang et al. (ACL Findings 2026): static layer-wise top-k schedules give 10-78 % throughput at "minimal" loss, >= 10 % on DeepSeek-V3 "without measurable loss"; ASET = a training-free adaptive policy. ACE: training-free, calibration-free token-adaptive skipping among the router's own top-k candidates by estimated slot contribution.
- HookMoE / PCoMoE / Expert-Sample (GOAL.md): > 50 % fewer activated experts with upper layers tolerating fewer; per-layer damage is uneven; greedy accuracy stable at half top-k on Qwen3-class fine-grained MoEs.
- Maps to us: uniform per-token k cuts are KILLed on this model (L1-17c top-6 2.98x error; the strict gate). The per-LAYER dimension is only half measured: DM P-frame says the middle layers (8-35) tolerate a full MoE-output reuse on sure rows (0.00-0.14 % flips) while 0-7 / 36-47 do not (19-23 %), and GOAL.md's Lever 2 proposes k_sure per layer. Nobody here has run "mid rows at k = 5-6 in layers 8-35 only": DM topk5 was all layers (mid 8.6 % code). That is a 10-minute decision-map arm.
