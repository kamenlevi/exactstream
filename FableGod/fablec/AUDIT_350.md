## 4. One new idea: Q1-UNION — on sure rows, drop only the experts no other row of the check needs (FAST, deterministic)

- **Mechanism.** The gate cuts the verifier's experts on drafter-sure rows to top-2 (Q1). Its byte and kernel savings come entirely from the union per block: misses are per distinct expert, the kernel pays 10.15 µs per (expert, tier) group. A sure row's rank 2-9 expert that another row of the same check also routes is in the union already: keeping it costs no bytes and no group, only a free slot in a 16-row tile. So on sure rows keep every expert that is in the check's union and drop only the ones that would be new. Bytes and groups are Q1's by construction; the decision depends only on the check's own routing, so it is deterministic and token-repeatable (unlike C1-2's resident fill, which it replaces).
- **Tonight's number [K replay_c2]:** of the pairs Q1 drops on sure rows, **52 % (θ 0.99) / 45 % (θ 0.9) are union members** — Q1-UNION keeps about half of what Q1 drops for nothing, so a sure row runs with ~6 of its 10 experts instead of 2.
- **Prior art.** Q1 (NOVELTY: new); cache-aware / sticky routing (I6, SWITCHCAP: KILL, substituting experts on all rows); MonoMoE and the ONNX GEMV path (padding waste, kernel side). No TRIED line keeps a cut expert because another row needs it. Adapted from Q1 [G].
- **Track, gain.** FAST, same-scores. Over Q1 it buys quality at zero cost, cashed as a lower θ: 0.9 vs 0.99 is groups ×0.66 vs ×0.79 (experts −3 ms at 12 rows) and SSD 24.3 vs 27.2 MB per kept token at C 320 [K §1.1] — **halved: −1.5 ms on the chain and −5 % bytes, ~+4 % tok/s over Q1 at 0.99.**
- **Cheapest test.** Bytes and groups: identical to Q1 by construction (the replay's union is unchanged). Quality: one arm in Breakthrough's map harness (GPU, ~1 h): sure rows under "top-2 + union members" at θ 0.99 and 0.9. **PASS: gated code flips ≤ 0.03 % at 0.99 (Q1: 0.09 %) and ≤ 0.5 % at 0.9. KILL: ≥ Q1's at the same θ.**
