## New bet tonight (named)
**Uncertainty-gated shared-expert budget**: use the faster shared-expert mode only where the model is confident (most code), full
experts elsewhere (most prose). Aim: pass the strict quality limit while keeping most of the +22-32 % on code. Prior art checked

**Update 21:01:** TrainLab's screen confirmed that no plain shared set passes the strict limit on top of the 3-bit format (as I had
predicted). The uncertainty-gated version DOES pass all four strict rules when the gate knows the model's confidence for the
pass (shared set on ~90 % of code, ~14 % of instruction text). Using the previous pass's confidence instead fails, because
code's risky tokens come as surprises. The deciding test is whether the draft head's own confidence (known before each pass)
works as the gate. If it does: ~+12-14 % on code under the strict limit; a fallback design gives ~+8-9 %. So the choice for you
is: strict limit -> ~+8-14 % on code only; task results as the bar -> +22-32 % on all text.
